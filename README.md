## filesystem
Создали функцию fs_delete которая ничего не возвращает (void) и принимает 1 аргумент константную строку (const char* file). Внутри функции делаем условие в котором вызываем фукцию remove(file) которая пытается удалить file. Если функция = 0 то она успешно удаляется, иначе вызывается ошибка удаления.
